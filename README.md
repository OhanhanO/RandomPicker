# 随机抽号器 RandomPicker

一个只有几百 KB 的单文件 Windows 小工具：设定号码范围，点一下抽一个号；按住 **Shift** 点「开始」会进入权重后台，可以给范围内每个号码单独设置抽中权重。

- 纯 Win32 + GDI 手写界面，**无第三方依赖**，静态链接，编译出来就是一个独立 exe。
- 支持高 DPI，Win10 / Win11 上界面清晰不模糊。

## 界面与操作

主界面四个部分：

| 区域 | 说明 |
| --- | --- |
| 起始号码 | 可手动输入，整数（允许负数） |
| 终止号码 | 可手动输入，整数（允许负数） |
| 抽中号码 | 显示抽出的号码；**可以直接手动改，但手动改的内容不参与抽取** |
| 开始 | 点击抽号，0.4 秒滚号动画后停在结果 |

快捷键：`Tab` 在三个输入框之间切换，`Enter` 等于点「开始」。

### 进入权重后台

**按住 Shift，再点「开始」**，界面切到后台：

- 列表里是当前范围内的每个号码，每行显示：号码、权重（0–10，默认 5）、以及它**实际的抽中概率百分比**。
- 点击某一行选中，直接按数字键输入权重，`Enter` 确认，`Esc` 取消输入。
- `↑` / `↓` 切换选中行；把鼠标放在权重格上滚滚轮可以 ±1 微调；在别处滚轮是翻页浏览。
- 顶部两个按钮：`全部设为 5`、`全部设为 0`。
- 底部 `保存并关闭` 保存权重并回到主界面（再按一次 `Esc` 也一样）。
- 权重会随号码记住：改范围时，还留在范围内的号码保留原权重，新出现的号码默认 5。

范围最大 100 万个号码。

## 权重是怎么换算成概率的

**权重是"相对份额"，不是每个号码的绝对概率。**

如果每个号码按 `权重 / 10` 独立算概率，那么 3 个号都是 5 时加起来就是 150%，10 个号就是 500% —— 单次抽取的总概率必须等于 1，所以只能做归一化：

```
号码 i 的抽中概率 = 权重 i ÷ 范围内所有号码权重之和
```

几个例子：

| 权重 | 结果 |
| --- | --- |
| `10 / 5 / 0` | 66.7% / 33.3% / 0% |
| `5 / 5 / 5` | 各 33.3% |
| `10 / 0 / 0` | 100% / 0% / 0% |
| `0 / 0 / 0` | 抽不了，界面会提示"所有权重都是 0" |

所以你想要的"能调到 0%~100%"是成立的：**把目标号设成 10、其余设成 0，它就是 100%；设成 0 就是永不抽中。**后台每一行都实时显示真实百分比，不用自己算。

权重 0 的号码会被完全排除在抽取池之外。

## 编译

### 方式一：GitHub Actions（不用装任何东西）

1. 在 GitHub 上新建一个仓库，把本目录的**所有文件**（含 `.github` 隐藏目录）推上去。
2. 打开仓库的 **Actions** 标签页，`build-windows` 会自动跑。
3. 跑完后点进去，页面底部 **Artifacts** 里下载 `RandomPicker-x64.zip`，解压就是 `RandomPicker.exe`。

工作流用的是 `windows-latest` + MSVC x64 + 静态 CRT，产出的 exe 不依赖 VC 运行库。

### 方式二：本机 MSVC

从开始菜单打开 **x64 Native Tools Command Prompt for VS**，`cd` 到本目录，运行：

```bat
build_msvc.bat
```

或者用 CMake：

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
```

产物在 `build\Release\RandomPicker.exe`。

### 方式三：本机 MinGW-w64

把 MinGW 的 `bin` 加进 PATH，然后：

```bat
build_mingw.bat
```

## 配置保存

权重和号码范围会存到 exe 同目录的 `RandomPicker.cfg`（纯文本，可手动编辑，删掉即恢复默认 1–50、权重全 5）。如果 exe 放在没有写权限的目录，保存会静默失败，不影响使用。

## 已知取舍

- 号码范围上限 100 万：内部为整个范围建了一张权重表，1 亿个号码会吃掉太多内存，所以做了限制。
- 权重是整数 0–10，配合归一化，多个号码之间的概率精度受这个刻度限制（这也是需求本身给的刻度）。
