# 随机抽号器 RandomPicker

单文件 Windows 小工具，抽号效果做成 CS 开箱卷轴：一排放号码的方框从右向左滚，最后停在中奖号上，那一格点亮成金色并播放音效。

- 纯 Win32 + GDI 手写界面，**无第三方依赖**，静态链接，编译出来就是一个独立 exe。
- 支持高 DPI，Win10 / Win11 上界面清晰不模糊。

## 主界面

| 区域 | 说明 |
| --- | --- |
| 起始号码 / 终止号码 | 可手动输入，整数（允许负数） |
| 开始 | 点一下开始摇号，约 4.8 秒后停在结果 |
| 卷轴 | 每个号码一个方框，按稀有度着色的边框和底条 |
| 抽中号码 | 显示抽中的号；可以直接手动改，但手动改的内容不参与抽取 |
| 音效开关 | 右上角，控制抽中时那声音效；状态会记住 |

快捷键：`Tab` 在三个输入框之间切换，`Enter` 等于点「开始」，`Shift + Enter` 进概率后台。

### 摇号过程

1. 按后台设定的概率当场抽出中奖号（**结果在动画开始前就定了**，卷轴只是演出）；
2. 卷轴从静止加速到约 3000 px/s，然后一路减速，最后轻微回弹一下停住；
3. 落点那一格从中奖前的中性配色**点亮成金色**：外发光脉冲 0.9 秒、边框加粗、底色转金；
4. 同时播放音效、把号码写进「抽中号码」。

滚动期间**所有格子都是普通稀有度**，金色只在停稳那一刻出现，不会提前剧透。

稀有度只是装饰，跟真实概率无关：

| 档位 | 颜色 | 卷轴里出现比例 |
| --- | --- | --- |
| 灰 | `#B0C3D9` | 55% |
| 蓝 | `#4B69FF` | 28% |
| 绿 | `#4CC38A` | 12% |
| 红 | `#EB4B4B` | 5% |

## 概率后台（Shift + 点「开始」）

每行的进度条和数字就是该号码**真实的抽中概率**，全部相加恒等于 100%。调高一个，其余按比例让出。

- **拖动进度条**直接改，吸附到 0.1%；
- 进度条上滚滚轮 ±1%；
- 选中行直接按数字键输入（如 `37`），`Enter` 确认；
- `↑ ↓` 换行、`PageUp / PageDown` 翻页、`Home / End` 到头尾、`← →` 微调 1%（按住 `Shift` 是 10%）；
- 右上角 `平均分配` / `全部清零`；
- 底部 `保存并关闭`（`Esc` 同效）。

范围最大 100 万个号码，概率随号码记住。

### 例子

| 操作 | 结果 |
| --- | --- |
| 把 7 号拖到 20% | 7 号 20%，其余 49 个号各 1.63% |
| 把 7 号拖到 100% | 7 号必中，其余全 0% |
| 把 7 号拖到 0% | 7 号永不抽中，其余按原比例占满 100% |

## 音效

`res/win.wav` 会被编译进 exe（Windows `WAVE` 资源），所以 exe 是单文件、不用带音频。抽中那一刻播放，右上角开关可以关掉。

如果资源因某种原因没打进去，程序会退回去找 exe 同目录的 `win.wav`，找不到就静音。

## 编译

### 方式一：GitHub Actions（不用装任何东西）

1. 在 GitHub 上新建一个仓库，把本目录的**所有文件**（含 `.github` 隐藏目录）推上去。
2. 打开仓库的 **Actions** 标签页，`build-windows` 会自动跑。
3. 跑完点进去，页面底部 **Artifacts** 里下载 `RandomPicker-x64.zip`，解压就是 `RandomPicker.exe`。

exe 里已经带了音效，不需要额外文件。

### 方式二：本机 MSVC

从开始菜单打开 **x64 Native Tools Command Prompt for VS**，`cd` 到本目录，运行：

```bat
build_msvc.bat
```

或者用 CMake：

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
```

产物在 `build\Release\RandomPicker.exe`。

### 方式三：本机 MinGW-w64

把 MinGW 的 `bin` 加进 PATH，然后：

```bat
build_mingw.bat
```

## 文件结构

```
RandomPicker/
├─ src/RandomPicker.cpp        # 全部源码（单文件）
├─ res/win.wav                 # 中奖音效（会被打进 exe）
├─ res/app.ico                 # 程序图标，16/32/48/64/128/256 六档
├─ res/app.rc                  # 资源脚本（bat 用）
├─ res/app.rc.in               # 资源脚本模板（CMake 用，自动填绝对路径）
├─ CMakeLists.txt              # CMake 构建（MSVC / MinGW 都支持）
├─ build_msvc.bat              # 一键 MSVC 构建
├─ build_mingw.bat             # 一键 MinGW 构建
├─ .github/workflows/build.yml # 推到 GitHub 自动构建
└─ preview/                    # 界面示意图
```

## 配置保存

范围、每个号码的概率、音效开关都存在 exe 同目录的 `RandomPicker.cfg`（纯文本）。删掉即恢复默认 1–50、概率均分、音效开。

## 已知取舍

- 号码范围上限 100 万；卷轴上的号码按真实概率抽取，0% 的号不会出现在卷轴里。
- 概率精确到 0.1%，极小值显示为 `<0.1%`。
- 卷轴 56 格，可见 6～7 格。
