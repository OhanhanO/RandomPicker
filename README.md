# 随机抽号器 RandomPicker

一个只有几百 KB 的单文件 Windows 小工具：设定号码范围，点一下抽一个号；按住 **Shift** 点「开始」进入权重后台，可以直接把范围内每个号码的概率调成 **0% ~ 100%**。

- 纯 Win32 + GDI 手写界面，**无第三方依赖**，静态链接，编译出来就是一个独立 exe。
- 支持高 DPI，Win10 / Win11 上界面清晰不模糊。

## 主界面

| 区域 | 说明 |
| --- | --- |
| 起始号码 | 可手动输入，整数（允许负数） |
| 终止号码 | 可手动输入，整数（允许负数） |
| 抽中号码 | 显示抽出的号码；可以直接手动改，但手动改的内容不参与抽取 |
| 开始 | 点击抽号，0.4 秒滚号动画后停在结果 |

快捷键：`Tab` 在三个输入框之间切换，`Enter` 等于点「开始」，`Shift + Enter` 进权重后台。

## 概率后台（Shift + 点「开始」）

列表里是当前范围内的每个号码，每行的进度条和右边的数字就是它**真实的抽中概率**。

- **拖动进度条**直接改概率，按住鼠标左右拖即可；
- 鼠标停在进度条上滚滚轮，±1%；
- 选中某行后直接按数字键输入（如 `37`），`Enter` 确认，`Esc` 取消；
- `↑ ↓` 换行，`PageUp / PageDown` 翻页，`Home / End` 到头尾；
- 选中行按 `← →` 微调 1%，按住 `Shift` 是 10%；
- 右上角两个按钮：`平均分配`（恢复成每个号均分）、`全部清零`；
- 底部 `保存并关闭` 保存并回到主界面（再按一次 `Esc` 也一样）。

范围最大 100 万个号码。概率会随号码记住：改范围时，还留在范围内的号码保留原概率。

---

## 概率是怎么定义的

**每一行的百分比就是它真实的抽中概率，所有行加起来恒等于 100%。**

因为一次只能抽出一个号，总概率必须是 100%，所以调高一个号，其余号码会自动按比例让出份额：

| 操作 | 结果 |
| --- | --- |
| 把 7 号拖到 20% | 7 号 20%，其余 49 个号各 1.63% |
| 把 7 号拖到 100% | 7 号必中，其余全 0% |
| 把 7 号拖到 0% | 7 号永不抽中，其余按原比例重新占满 100% |
| 点「平均分配」 | 每个号 100 ÷ 号码个数 |

概率为 0% 的号码不会进入抽取池；如果所有号码都是 0%，会提示「范围内所有号码都是 0%」。

## 编译

### 方式一：GitHub Actions（不用装任何东西）

1. 在 GitHub 上新建一个仓库，把本目录的**所有文件**（含 `.github` 隐藏目录）推上去。
2. 打开仓库的 **Actions** 标签页，`build-windows` 会自动跑。
3. 跑完后点进去，页面底部 **Artifacts** 里下载 `RandomPicker-x64.zip`，解压就是 `RandomPicker.exe`。

工作流用的是 `windows-latest` + MSVC x64 + 静态 CRT，产出的 exe 不依赖 VC 运行库。

### 方式二：本机 MSVC

从开始菜单打开 **x64 Native Tools Command Prompt for VS**，`cd` 到本目录，运行：

```bat
build_msvc.bat
```

或者用 CMake：

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
```

产物在 `build\Release\RandomPicker.exe`。

### 方式三：本机 MinGW-w64

把 MinGW 的 `bin` 加进 PATH，然后：

```bat
build_mingw.bat
```

## 配置保存

范围和每个号码的概率会存到 exe 同目录的 `RandomPicker.cfg`（纯文本，可手动编辑，删掉即恢复默认 1–50、概率均分）。如果 exe 放在没有写权限的目录，保存会静默失败，不影响使用。

## 已知取舍

- 号码范围上限 100 万：内部为整个范围存了一张概率表，更大的范围会占太多内存。
- 概率精确到 0.1%（拖动和滚轮都吸附到 0.1%），极小的概率在列表里显示为 `<0.1%`。
